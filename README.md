## Metodología

El aprendizaje se realiza principalmente mediante práctica. Cada tema se acompaña de ejercicios y pequeños proyectos con el objetivo de comprender los conceptos y desarrollar la capacidad de resolver problemas de forma independiente.

El repositorio también funciona como un registro del progreso y evolución del aprendizaje.

## Objetivo final

Construir los conocimientos y un portafolio de proyectos suficientes para comenzar a buscar mi primer empleo relacionado con Inteligencia Artificial / Machine Learning y continuar especializándome profesionalmente en el área.
